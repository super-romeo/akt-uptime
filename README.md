# akt-uptime

Внешняя проверка доступности https://akt.veridok.ru раз в 5 минут (GitHub Actions). Успех — сигнал в Healthchecks
(секрет `HC_PING_URL`), сбой — сигнал `/fail` с причиной. Проверяются главная, анкета экспресс-проверки и адрес тарифов.

GitHub выключает расписание в публичном репозитории после 60 дней без коммитов — тогда Healthchecks пришлёт тревогу
о молчании, и расписание включается кнопкой на вкладке Actions.
